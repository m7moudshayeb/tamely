# Contributing

Tamely is a concept project, but ideas are welcome.

- Open a pull request and fill in the template: **What's proposed** and **What it delivers**. A check fails until both are filled in.
- Pull requests are squash-merged, and the description becomes the commit message on `main`.
- Only the maintainer can approve and merge.
- Security issues: please use GitHub's private vulnerability reporting (Security tab), not a public issue.
